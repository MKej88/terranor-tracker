VEIEN VIDERE

Neste steg

  1. Fullfør automatisk innlasting av historiske svenske værdata.
  2. Bygg normalvær og mål om været er bedre eller dårligere enn normalt.
  3. Koble værforholdene til kontraktsvekt og mulige utslag på aktivitet og margin.
  4. Fyll signalregisteret med kildebelagte tilleggsarbeider og nye bestillinger.
  5. Etter Q2: legg inn faktiske tall, kalibrer modellen én gang og lås Q3-metodikken.

DATAKILDER

Hva værkildene betyr

Veivær fra TrafikverketSvenske målestasjoner langs veiene. Gir blant annet veibanetemperatur, lufttemperatur, vind, nedbør og snø. Trafikverkets system kalles VViS.
Vanlige svenske værstasjonerOffisielle værmålinger fra Sveriges meteorologiske og hydrologiske institutt, forkortet SMHI. Brukes også til historikk og sammenligning mot normalt vær.
Danske værdataPlanlagt kilde fra Danmarks Meteorologiske Institut, forkortet DMI, for kontrakter i Danmark.
Finske værdataPlanlagt kilde fra Finlands meteorologiske institutt, forkortet FMI, for kontrakter i Finland.
Værbasert arbeidsegnethetEn samlet score for hvor gunstig været er for planlagt drift og vedlikehold. Dette er ikke et direkte omsetningsestimat.
Historisk normalViser om forholdene er bedre eller dårligere enn det som er vanlig på samme sted og samme tid på året.
